# Карта кода

## Дерево

```
gradebook/
├── docker-compose.yml          # 4 контейнера: api, db, redis, mailpit
├── .env.example                # имена переменных без значений
├── .gitignore                  # .env, __pycache__, *.pyc — исключены
├── README.md                   # как запустить
├── db/
│   ├── 01_schema.sql          # все таблицы: users, courses, enrollments,
│   │                          # grades, retake_requests, audit_log
│   ├── 02_roles.sql           # GRANT для app_api; app_api не имеет DROP/CREATE
│   └── 03_seed.sql             # пусто (тестовые данные сеются из api/app/seed.py)
├── api/
│   ├── Dockerfile
│   ├── requirements.txt
│   └── app/
│       ├── main.py             # FastAPI app; lifespan; StaticFiles для web/
│       ├── config.py          # чтение .env
│       ├── db.py               # пул asyncpg
│       ├── redis_client.py     # клиент Redis
│       ├── security.py          # Argon2id hash_password / verify_password,
│       │                       # JWT create / decode
│       ├── deps.py             # get_current_user, require_roles
│       ├── schemas.py          # request/response модели (системные поля не входят)
│       ├── errors.py           # middleware: исключение → 500 {"detail": "Внутренняя ошибка"}
│       ├── mail.py             # отправка в SMTP (Mailpit)
│       ├── seed.py             # тестовые пользователи + курс CS-101 + оценки
│       └── routers/
│           ├── auth.py         # O-07 / 3.1 / 3.2 / 3.3
│           ├── grades.py       # O-01 (чтение по id), O-03 (PATCH), O-04 (список)
│           ├── retake.py       # O-02 (создать), O-06 (501 заглушка)
│           ├── courses.py      # O-08 (список + детали)
│           └── admin.py        # O-05 (подтверждение), O-09 (аудит)
├── web/
│   └── index.html              # SPA: вход/регистрация, мои оценки,
│                               # заявка на пересдачу, таблица оценок для staff
└── requests/
    ├── auth.http               # коллекция аутентификации
    ├── business.http            # коллекция бизнес-операций
    └── curl_checks.ps1         # PowerShell-скрипт для прогонки
```

## Где находится каждая защита

| Защита из ЛР № 1–2 | Файл и функция |
|---|---|
| Хэш пароля Argon2id + соль + pepper | `api/app/security.py::hash_password` |
| JWT подпись (секрет из окружения) | `api/app/security.py::create_access_token` |
| Проверка подписи и срока | `api/app/security.py::decode_token` |
| Отзыв токена (logout) | `api/app/redis_client.py` + `routers/auth.py::logout` |
| Роль из БД, а не из тела запроса | `api/app/deps.py::get_current_user` |
| Объектная авторизация (student ↔ своя оценка) | `api/app/routers/grades.py::get_grade` — строка `row["student_id"] != user.id → 404` |
| RBAC (кто может PATCH) | `api/app/routers/grades.py::patch_grade` — `require_roles("teacher","employee")` |
| Лишние поля из тела отбрасываются | `api/app/schemas.py` — в request-моделях нет `owner_id / status / role / student_id` |
| Оптимистичная блокировка | `api/app/routers/grades.py::patch_grade` — `UPDATE ... WHERE id=$1 AND version=$2`; 0 строк → 409 |
| Повторная заявка на пересдачу | `api/app/routers/retake.py::create_request` — проверка существующей `pending` |
| Нейтральный 500 (без стека/SQL) | `api/app/errors.py` |
| Параметризованный запрос (без склейки SQL) | везде `pool.fetch("... $1 ...", value)` |
| Аудит изменений | `api/app/routers/admin.py::confirm_grade` и `patch_grade` пишут `audit_log` |
| Приложение без DDL-прав на БД | `db/02_roles.sql` — GRANT SELECT/INSERT/UPDATE/DELETE |
