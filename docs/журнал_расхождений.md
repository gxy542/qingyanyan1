## Общее замечание

Система реализована по контрактам ЛР № 2. Архитектура, эндпоинты, схема данных
и блоки безопасности перенесены в код без изменений.

## Прочие решения, подтверждённые без изменений

- Пароли: **Argon2id** + случайная соль + pepper из окружения.
- Токены: **JWT (HS256)**, в Redis хранится allowlist; logout и смена пароля немедленно отзывают токен.
- БД: PostgreSQL 16, приложение под отдельной ролью `app_api` (без прав DDL).
- Оптимистичная блокировка по колонке `version`; повторный `PATCH` со старой версией → `409`.
- Объектная авторизация: студент при обращении к чужой оценке получает `404` (а не `403`).
- Все непредвиденные ошибки возвращают нейтральный `500`, стек — только в лог.
